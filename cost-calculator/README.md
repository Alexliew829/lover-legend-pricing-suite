# 成本与售价计算器 V10.8

- 优先读取 Import System 同源资料，云端在后台刷新。
- 支持所有当前产品前缀、旧 PZ 编号及三个已确认的 PS/PZ 历史别名。
- 当前真实编号优先，别名发生歧义时不自动错误匹配。
- 产品选择即时响应；实际售价手动修改后不会被后台覆盖。
- 嵌入 Pricing Suite 时只转发被动触摸位置，由外层统一处理刷新，不拦截原生滑动。


V10.8: 选择进口系统已有产品时，实际利润以 Import averageCost 为唯一成本基础；VND 花盆、木架+本地运费、主播佣金读取 Import V20.6 当前设置。手动输入新产品仍沿用原估算模式。
