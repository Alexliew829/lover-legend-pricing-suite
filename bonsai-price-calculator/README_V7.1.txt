Kalkulator Harga Bonsai V7.1

V7.1 以 V7.0 为唯一基准，只修改无编号/手动门市价的最低售价取整：
- 门市 <= RM500：最低售价 = 门市 x 80%，按最接近 RM10 取整。
- 门市 > RM500：最低售价 = 门市 x 80%，向上取到尾数 80 的售价档。
- 门市 -> 直播售价逻辑完全保持 V7.0/V6.9，不修改。
- TikTok、有编号产品、Import 最低售价与产品反推直播逻辑全部不修改。
- 产品搜索、缓存、运费、汇率、Postcode、台湾/印尼逻辑、UI及其他稳定逻辑全部不改。

验收例：
- RM389 -> 最低 RM310。
- RM480 -> 最低 RM380。
- RM580 -> 580 x 80% = 464 -> 尾数80档 RM480。
- RM3,980 -> 3,184 -> 尾数80档 RM3,180。
- RM4,280 -> 3,424 -> 尾数80档 RM3,480。

Apps Script / Code.gs：不需要更新。
Import System：不需要修改或重新部署。
