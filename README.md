# Lover Legend Pricing Suite V10.3

- 上半部：成本与售价计算器 V10.3；下半部：盆景价格计算器 V6.1。
- 两个计算器支持 Import V16.4 当前产品编号、旧 PZ 编号，以及 PS0001→BX0001、PS0002→AS0002、PZ0006→BX0006。
- 当前真实编号优先；真正的 PS 花盆编号不会被旧别名覆盖。
- V6.1 单独打开时保留自己的下拉刷新；嵌入套装时关闭子页面刷新，只由 V10.3 外层刷新。
- 外层和两个内嵌页面只被动观察触摸，不拦截手机原生上下滑动；产品列表滑动不会触发选择。
- 只在整页顶部继续下拉并超过触发距离时刷新。
- 未修改成本、售价、利润、最低售价、运输、汇率或其他计算公式。
